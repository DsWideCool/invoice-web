# Task 025: 클라이언트 견적서 화면 격리

## 개요

관리자로 로그인된 브라우저에서 공개 견적서 링크를 열면 "목록으로"가 보여, 링크를 받은 사람이 관리자 경로로 이동할 수 있는 것처럼 보였다. 공개 견적서 화면에서 관리자 요소를 모두 없애고 관리자용 견적서 상세를 분리한다(F020 보완).

## 관련 파일

- `src/app/invoice/[id]/page.tsx` - 관리자 세션 확인·"목록으로" 제거
- `src/app/(admin)/admin/(dashboard)/invoices/[id]/page.tsx` - 관리자용 상세(목록으로·링크 복사·클라이언트 화면)
- `src/components/invoice/invoice-view.tsx` - 견적서 본문 공용 컴포넌트
- `src/lib/invoice-url.ts`, `src/components/admin/invoice-list.tsx` - 목록 행은 `getAdminInvoicePath`로 이동

## 수락 기준

- [x] 공개 견적서 화면에는 로그인 여부와 무관하게 `/admin` 링크가 없다
- [x] 관리자 목록의 행을 누르면 `/admin/invoices/<ID>`로 이동한다
- [x] 관리자용 상세에서 목록으로 돌아가기, 링크 복사, 클라이언트 화면(새 탭) 열기가 가능하다

## 구현 단계

- [x] 1단계: 견적서 본문 컴포넌트 분리
- [x] 2단계: 공개 화면 단순화, 관리자용 상세 추가
- [x] 3단계: 목록 링크 대상 변경

## 테스트 체크리스트

- [x] 관리자 로그인 브라우저에서 공개 견적서 화면의 링크 목록에 `/admin` 경로 없음
- [x] 목록 행 → 관리자용 상세 → "목록으로" → `/admin`
- [x] 관리자용 상세의 "클라이언트 화면" 링크가 `/invoice/<ID>`

## 변경 사항 요약

- 공개 견적서 화면은 더 이상 관리자 세션을 읽지 않는다
- 견적서 URL을 아는 사람은 누구나 그 견적서를 볼 수 있다는 점(URL이 접근 수단)은 기존과 같다
