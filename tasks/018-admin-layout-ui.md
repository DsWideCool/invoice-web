# Task 018: 관리자 레이아웃 UI 완성

## 개요

Task 016에서 만든 관리자 레이아웃 골격을 반응형으로 완성하고, 목록 로딩 스켈레톤과 Notion 조회 실패 에러 화면을 실제 형태로 만든다(F020).

## 관련 파일

- `src/components/admin/admin-header.tsx` - 375px 아이콘 버튼 / 640px 이상 메뉴·텍스트
- `src/components/admin/logout-button.tsx` - 모바일 아이콘 전용, 로딩 표시
- `src/app/(admin)/admin/(dashboard)/loading.tsx` - 카드형(모바일)·테이블형(640px 이상) 스켈레톤
- `src/app/(admin)/admin/(dashboard)/error.tsx` - 안내 문구, 오류 코드, `router.refresh()` + `reset()` 재시도

## 수락 기준

- [x] 375px에서 헤더는 서비스명과 아이콘 버튼만, 640px 이상에서 메뉴와 "로그아웃" 텍스트가 보인다
- [x] 로그인 화면은 헤더 없는 중앙 카드 레이아웃이다
- [x] 새로고침 버튼은 목록 페이지 상단에 있다
- [x] 스켈레톤이 실제 목록과 같은 카드/테이블 형태다
- [x] Notion 조회 실패 시 에러 화면과 "다시 시도" 버튼이 표시된다
- [x] 375px·1280px에서 가로 스크롤이 없다

## 구현 단계

- [x] 1단계: 헤더 반응형 처리, 인쇄 시 숨김
- [x] 2단계: 목록 스켈레톤 카드/테이블형 분리
- [x] 3단계: 에러 화면 재시도(서버 컴포넌트 재요청 후 경계 초기화)

## 변경 사항 요약

- 헤더 메뉴는 서비스명 링크와 중복되므로 모바일에서 숨김
- 에러 화면은 `error.digest`가 있으면 오류 코드를 함께 표시
- 확인: 1280px·375px 스크린샷, 잘못된 `NOTION_API_KEY`로 실행한 프로덕션 서버에서 에러 화면·재시도 확인
- 768px은 별도로 확인하지 않음(640px 이상은 1280px과 같은 테이블 레이아웃)
