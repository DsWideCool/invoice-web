# Task 020: 목록 링크 복사 버튼 UI 구현

## 개요

관리자 목록의 테이블 행과 모바일 카드에 클라이언트용 링크 복사 버튼을 추가한다. 버튼을 눌러도 상세 페이지로 이동하지 않아야 한다(F021).

## 관련 파일

- `src/components/admin/copy-link-button.tsx` - 아이콘 버튼 + 툴팁, 2초 체크 아이콘, 수동 복사 다이얼로그
- `src/components/admin/invoice-list.tsx` - 테이블 액션 열, 모바일 카드 구조 변경

## 수락 기준

- [x] 테이블 행과 모바일 카드 모두에 복사 버튼이 있다
- [x] 클릭·Enter로 동작하고 상세 페이지로 이동하지 않는다 (Space는 네이티브 `<button>` 기본 동작)
- [x] `aria-label`에 견적서 번호가 포함된다
- [x] 모바일 터치 영역이 40px 이상이다
- [x] Clipboard API를 못 쓸 때 URL을 직접 선택·복사할 수 있는 UI가 있다

## 구현 단계

- [x] 1단계: `CopyLinkButton` 작성
- [x] 2단계: 테이블 액션 열 추가, 버튼에 `relative z-10`으로 행 링크 오버레이 위에 배치
- [x] 3단계: 모바일 카드를 `<li>`(카드) 안에 "링크 영역 + 버튼"으로 분리(`<a>` 안 `<button>` 중첩 제거)
- [x] 4단계: 수동 복사 다이얼로그(읽기 전용 입력, 포커스 시 전체 선택)

## 변경 사항 요약

- 모바일 카드 hover 배경은 `has-[a:hover]`로 링크 영역에 마우스가 있을 때만 적용
- 버튼 크기: 모바일 40px(`size-10`), 640px 이상 32px
